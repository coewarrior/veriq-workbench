# 执行架构独立对照原型

用户授权：将企业知识库这轮真实执行问题转为可重复实验，比较覆盖、误阻塞和效率，不继续只改提示词。

本目录是独立实验，不接入应用请求路由，不修改生产 planner、MCP、Skill、用例生成、授权、报告结果或默认测试流程。原始用户会话、报告、凭据和业务数据不入库；场景只保留抽象问题和合成数据。输出应放在已忽略的 `output/playwright/`。

## 对照的边界

- **基线是故障片段和策略的受控回放**，不是再次运行原智能体，也不代表原任务的最终结果。原任务后来发现了提交按钮并继续执行。
- 状态执行器在同一个页面用同一组浏览器动作完成目标。它使用明确业务状态、当前可见范围、SQLite WAL/FULL事件记录、重启后可见结果核对、核心路径优先顺序。
- 第三组 `corrected` 只修正漏点提交和已知动态选择，保留原依赖作用域、格式优先和易失恢复方式；用于避免把简单动作修正收益全部归功于新架构。
- 原型没有引入 Temporal/LangGraph 服务，也不声称框架本身带来收益；先验证它们所代表的机制是否值得建设。没有模型调用，不测模型选择正确动作的概率。
- 规则实验直接导入本次 main 的 `test_checkpoints.plan`。两组只改依赖作用域。同一原始用例的独立断言展开为相同三个检查点；基线仍在用例级绑定未知规则，候选仅在 policy 点绑定。收益归于设计结构，不归于 planner 替换。
- 提交后进程退出是故障注入：原轮只观察到回写滞后，没有崩溃证据。恢复使用两个独立Node进程，退出点在已观察业务写入、结果提交之前。候选通过已有意图和页面对象匹配恢复，不声称任意远端操作 exactly-once。
- 格式优先实验缩约为9个格式任务与6个核心状态任务，两组最终执行完全相同的15项。前6项预算只测覆盖分布，绝不是停止测试的产品规则。格式名是调度代理，仿真不测真实格式解析。
- 阈值与确认框变体是预先指定的可见配置，**不是隐藏测试集**；若要判断泛化，需另行准备未知站点与真正留出场景。

## 运行

需要 Node 22.13+（node:sqlite）、已安装的 Playwright 与 Chromium/Chrome，以及项目 Python 3.11+环境。不自动下载依赖、不读浏览器Cookie、不调用外网业务。

```bash
PLAYWRIGHT_MODULE=/absolute/node_modules/playwright/index.mjs \
BENCH_PYTHON=/absolute/project-venv/bin/python \
node experiments/execution-benchmark/run.mjs output/playwright/execution-benchmark/run-001
```

可设 `BENCH_REPEATS=1` 调试；正式默认5次，三组顺序轮换，解析延迟按重复次数变化。`BROWSER_CHANNEL` 默认 chrome。每次使用新输出目录。所有浏览器HTTP请求被限制为本次随机端口的 loopback origin。启动页面、浏览器进程、服务器均由实验自己拥有并在finally关闭。

结果 `index.html` 可以直接打开；含逐场景截图、动作JSONL、独立系统状态、浏览器trace、规划器输入输出、源码SHA-256和逐次指标。`trace.zip` 可用 Playwright trace viewer 查看。用户原始记录不复制到输出。

## 指标与对照保护

1. 断言分母在 `protocol.json` 预先定义，失败被正确发现也算已验证，不能把“通过率”当“覆盖率”。
2. 仿真服务器独立记录真实效果，执行器只通过页面取证，不能读隐藏评分状态。
3. 错误 blocked 事件和被规则误挂起的独立断言计为误阻塞；真实权限缺失必须保留。
4. 空文件无反馈缺陷必须在两组检出。不得依赖自动恢复隐藏该缺陷。
5. 完整相同工作负载耗时、前段核心覆盖、重复写入分开评价。提前错误停止的基线不能拿来宣称候选更慢/更快。
6. 记录动作数不等于LLM工具调用数。没有测付费成本、模型延迟、真实业务覆盖或统计显著性。

## 架构

`protocol.json → 场景初态 → 相同浏览器适配器 → 回放策略 / 状态执行器 → 独立状态判定 → HTML报告`

`planner.py`复用生产代码；`fixture.*`拥有合成系统；`executor.mjs`拥有动作和事件记录；`run.mjs`仅负责隔离、顺序、进程故障、评分；`report.mjs`只消费结果。生产调用方不导入本目录。

下一步若机制实验支持继续投入，应使用相同模型、相同输入和预算，在独立测试环境做在线策略A/B；让模型生成状态图而非手工写好后再把改善归功于模型。此次结果只支持或否定这些机制。
