# API 测试台网页版 v0.4.0

网页入口：`http://192.0.2.20:18089`。服务部署到 `/home/veriq/apps/api-test-web`，与五子棋 API 的 `18081` 端口独立运行。

## 会话与 API 管理

左侧提供新建测试会话、历史会话和独立 API 管理。四个步骤只出现在当前会话内部；导入成功后才能生成，生成后才能执行，执行后才能查看报告。可以返回完成的步骤查看依据，每个会话独立保留文档、用例、所选模型 API 与历次报告。

API 管理支持最多30套配置，每套包含配置名称、服务商、协议、地址、模型名称、加密Key、输出上限和无响应等待时间。支持新增、编辑、显式测试连接、选择和删除。创建新配置不会继承其他配置的Key。原有单配置会自动迁移保留。

生成步骤的下拉框选择本会话使用的API；修改默认配置不会改变已经绑定其他API的会话。删除正在使用的配置后，需要重新选择，系统不会偷偷改用其他服务。保存/选择API不会发出模型请求；只有测试连接或生成才会调用。

## 用户流程

1. **导入接口文档**：粘贴或上传 Markdown、OpenAPI 3 JSON/YAML；也可选择五子棋或资源管理示例。
2. **生成测试用例**：选择文档规则生成、内置示例方案，或配置自己的模型 API 后生成候选用例。模型给出的预期需要核对后采纳；依据不足和危险场景保留未执行原因。
3. **执行测试用例**：选择目标测试环境。服务端先进行静态校验，再按用例执行前置步骤、请求、断言及数据清理。
4. **查看测试报告**：查看 HTML 报告与执行明细，并下载用例、环境配置和 JSON 结果。网页同时提供 CLI 使用入口，网页与 CLI 使用同一个执行器。

内置资源管理服务仅监听 Web 容器的回环地址，不向宿主机发布端口。内置五子棋连接已经部署的 `http://192.0.2.20:18081`；仅删除本轮生成的 `mvp_` 测试账号，不清空数据库、不重启五子棋服务。

## 模型 API

用户填写供应商、协议、Base URL、模型名称 与 API Key。适配四种调用协议：OpenAI Responses、OpenAI Chat Completions 兼容协议、Anthropic Messages、Google Gemini GenerateContent。提供 OpenAI、DeepSeek、通义千问、智谱、Kimi、豆包、MiniMax、Claude、Gemini 和自定义服务的配置预设。

具体可调用模型由用户账户、服务区域及供应商权限决定；预设不代表所有模型都已实测。连接测试和模型生成会调用用户填写的模型 API，按该账户计费；规则生成和内置方案不调用模型。

API Key 在服务端使用 Fernet 加密保存。模型配置 API 默认仅返回是否已配置密钥，不回显密钥或密文。服务当前使用内网 HTTP；需要跨不可信网络使用时，应由部署者配置域名及 HTTPS。

项目和模型配置按浏览器会话隔离。请保留该浏览器的站点 Cookie；更换浏览器、清除 Cookie 或使用隐私窗口后，不能自动恢复此前项目。当前不提供账户注册、团队共享或密码找回。

## 部署

平台源码位于独立的 `api-test-workspace` 仓库。所有发布通过 GitLab main 合并与专用 Jenkins `api-test-workspace/deploy-main` 完成，成功上线后同步确切提交到 Gitee 专用仓库。

操作流程以仓库内 `docs/JENKINS_RELEASE.md` 为准。`deploy/web/deploy-web.sh --package-only` 由流水线用于打包，不手工替换运行服务。

## 运维

登录服务器后执行：

```bash
cd /home/veriq/apps/api-test-web
docker compose ps
docker compose logs --tail 100 web
docker compose stop
docker compose start
```

普通重启和重新部署保留数据卷。不要使用 `docker compose down --volumes`，该命令会删除网页项目、报告和加密密钥。请勿把完整 `.env`、`docker compose config` 输出或容器环境变量加入交付包；配置校验使用 `docker compose config --quiet`。

网页任务串行执行真实 API 场景；模型生成使用独立后台任务。更新服务前应等待当前任务完成。浏览器 Cookie 会持久保存，后台任务状态在进程重启后不会自动接续；已保存的用例与报告仍保留。

## 实际处理顺序

网页导入 → 校验大小和文档内部引用 → 解析接口契约和来源摘要 → 保存项目 → 规则生成或显式调用模型 → 校验模型输出与证据、标记候选 → 使用者采纳候选预期 → 冻结用例 → 校验测试环境并固定DNS目标 → 串行HTTP请求、变量提取、断言与清理 → 保存请求证据及用例快照 → 生成HTML报告。

CLI共用相同的解析、生成、校验、执行和报告模块。当前未接入RAG、向量库、定时任务或多用户账号系统。

## 已知边界

- 文档上限1 MB、单次最多200条候选/180个可执行请求。
- OpenAPI3或示例格式Markdown；Swagger2、PDF/Word、任意自然语言Markdown暂不支持。
- 仅内部 `#/` 引用；正则Schema `pattern`、`patternProperties` 暂不支持，以免不受控正则阻塞服务。
- 自动生成仅依照明确响应契约。鉴权、数据依赖或写操作清理信息不足的候选不会直接执行。
- 自定义地址要求公网HTTPS，其他内网服务需要管理员配置；模型名称和区域必须与账户权限匹配。
- 会话Cookie丢失不能恢复当前项目。后台任务不跨服务重启续跑，已保存报告和方案保留。

## v0.3.1 模型等待方式

模型调用请求流式响应。配置中的 `timeout` 表示连续未收到数据的等待秒数（默认 90 秒），不限制整个生成过程的总耗时。收到内容、推理增量或连接心跳时继续等待；连接建立最多等待 10 秒。

网页显示等待响应、模型思考中、接收结果等进度，不展示或保存推理原文。服务商的 HTTP 错误与流内错误分别处理；输出截断或缺少结束标记不会保存为成功用例。不进行自动重试或自动切换模型。

兼容网关若仍返回普通 JSON，会读取同一次响应并保留无响应等待限制；不会额外发送请求。接口不支持流式请求并明确报错时，显示其错误。

## v0.3.2 自动输出额度

「单次输出额度」默认留空，表示自动配置，无需预估答案长度。DeepSeek V4 Flash/Pro/Flash Vision Exp 按已验证的官方容量设置为 384,000 Token；手动填写的正整数原样传给服务商，工具不再设 16,384 上限。额度是允许的最大值，不要求生成满额；实际用量以服务商统计为准。

Anthropic 自动模式在生成前查询所选服务 `/models/{model}` 的 `max_tokens` 能力字段；服务不提供该信息时明确提示手动填写，不猜测小额度。其他未收录模型的可选输出参数省略，由服务默认值决定。网关若具有自己的容量限制，可手动覆盖；不做额外的自动重试。

旧版强制范围内的网页配置一次性迁移为自动，保留 API 名称、Key 和会话选择，原数值在内部迁移记录中保留。迁移后用户新填写的小额度也会正常保留。CLI 将 `max_tokens` 设为 `null` 或省略即可自动。

流式响应接收保护阈值提高到 128 MiB，用例文本与结构化 JSON 的解析保护阈值提高到 16 MiB；这些属于服务资源保护，不是 Token 额度。用本地模拟服务验证了 3 MiB 用例响应经过接收、校验、保存、采纳、执行与报告生成。

本版仍是单次模型生成，模型自身的上下文/输出容量仍然有效；长文档自动分批与续跑尚未实现。

### 导入文档中的测试地址

导入页会识别 OpenAPI 根级 `servers`（变量使用声明的 `default`）和 Markdown 明确标注的 `Base URL` / `基础地址` / `服务地址`。多个地址可选择，手动修改不会被后续识别覆盖；相对地址或未定义变量需补充完整地址。仅检查文档时可留空。

Base URL 随会话保存。执行页与 Codex 显示同一个地址，CLI 下载的 `environment.json` 也使用该地址。支持 `/v1` 等基础路径，执行时与文档接口路径拼接；导入不会探测目标地址或自动开放内网访问。已有会话可返回导入步骤保存地址，不改变历史报告。
