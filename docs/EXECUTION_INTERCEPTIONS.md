# 执行拦截清单（0.17.36）

本文区分拒绝单个新操作、暂停一个分支和撤销整份租约，不以“安全”统一解释。

| 入口 | 触发条件 | 当前后果／范围 | 本次处理 |
|---|---|---|---|
| direct_execution._owned / _account | owner/holder/账号/epoch/revision不匹配，或任务已停止 | 拒绝该调用；不停止别的模块 | 保留，避免串号与停止后继续写入 |
| DirectExecution.browser | 同request_id不同载荷、同租约尚有在途命令 | 拒绝冲突的新命令，原命令继续 | 保留原回执，不另起恢复循环 |
| operation_begin / complete | 旧操作已确认、pending或unknown | 已确认取原结果；未知写入需核实，读取可用 | 原计划复用确定操作ID，不重发未知动作 |
| browser_policy / managed_browser请求守卫 | 共享/准备阶段未经核验的请求、跨身份影响 | 拦截该请求，要求独占；普通独占沿原授权 | 本次不增加策略规则 |
| browser_batch | 实际断言失败、工具未知、分支需独占 | 停止该批后续步骤，返回已完成与未执行 | 用例计划立即保存该条观察，不自动换ID重启 |
| case_execution | 保存超时或冲突 | 停止计划后续用例，保留pending_save | 不重跑业务补报告；不阻塞其他租约 |
| 辅助channel.register | 非独占、执行机不支持、额外容量不足 | 拒绝辅助登记 | 应只结束未启用辅助；本次补关闭证据，避免误伤主租约 |
| managed_browser.register_auxiliary | 绑定/PID/目录归属错误，或进程丢失且退出不明 | 辅助绑定失败→父租约隔离撤权 | 保留真实身份不明；路径别名修复及已关闭证明收敛 |
| lease-channel登记请求 | 10秒请求期限到达 | 旧版浏览器关闭后无退出证明；晚登记造成误撤权 | 关闭成功先落closed与startup-failure，再补closed回执，不扩超时 |
| auxiliary_bound | host绑定错误与closed回执竞争 | 旧版可在exited后仍撤权父租约 | exited保持终态，迟到绑定错误不撤权 |
| expire_leases | 启动120秒、辅助失联40秒、无进展600秒、人工等待1800秒 | 原范围撤权并确认退出，不直接宣称账号空闲 | 不改时限；相同checkpoint不伪造新进展 |
| save_cases | revision、用例/检查点、依赖/状态或证据不合法 | 拒绝保存，不代表业务操作未发生 | 仍保存真实数据，不靠删除检查点迎合校验 |
| return_account /隔离结算 | 未退出、未知操作、保留现场 | 保留对应账号，不重派 | 不改库伪造退出，不影响其他独立账号 |
| Jenkins发布 | 活动轮次、通道、收尾、ACK未结束 | postponed，不切换服务 | 等01自然交还，原流水线发布 |

平台无法仅通过MCP返回值停止任意外部聊天的模型推理。已知计划在Runner中运行；资源等待返回结束轮次的结构化结果，协调者负责外部会话休眠和唤醒，不把发送提示当作进程控制。
