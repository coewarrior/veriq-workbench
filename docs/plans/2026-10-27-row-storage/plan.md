# 实施计划（用户修订 PostgreSQL）

1. PostgreSQL 持久化：连接/配置、规范化元数据与历史、只读快照、差量行写；登录账号/会话同库迁移。
2. 调用方：全部运行路径移除 SQLite，单节点结果写与调度授予区分锁域，保留业务规则/DB→Store锁序。
3. 迁移/发布：独立服务与secret、标准隔离启动检查、活动保护、旧服务停止后导入/完整校验、候选禁写、健康后激活；首次激活后禁止旧 SQLite 回滚，恢复始终使用 PostgreSQL 当前数据。
4. 静态检查、独立评审、同步main与MR合并；Jenkins成功发布，实际backend/schema/version/SHA核对后Gitee确切SHA同步。

Review Focus：JSON特殊key/类型/映射顺序，未访问历史零加载；并发不丢改动、原授予公平与原子性、只读不阻塞写、无跨锁域死锁/副作用重放；全部SQLite入口包括账号目录与独立活动探针；迁移中断/健康失败/切换后回滚；不对当前测试做任何操作。
