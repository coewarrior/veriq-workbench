# 内网账号登录

打开首页即可注册或登录，无需邮箱、验证码或管理员审批。账号 3–32 位（字母、数字、点、横线、下划线，不区分大小写），密码 6–128 位。所有账号权限相同，仅能访问自己的工作空间。

## 数据归属

首次注册使用当前浏览器原有的工作空间作为账号空间，保留原文、测试会话、报告、模型 API、PingCode 配置和已经授权的 MCP 连接。原有文件和报告地址不变。换浏览器登录同一账号会读取同一份数据；登录已有账号不会自动合并另一个浏览器的匿名资料。

完整报告 URL 可在内网免登录只读查看，便于直接分享测试结论。项目列表、接口原文、原始 JSON、账号配置、Codex 授权和 PingCode 推送仍需登录，匿名查看页不提供修改或提交入口。

账号关系与登录凭据保存在持久卷 `/data/accounts.sqlite3`；密码使用随机盐和 scrypt 哈希，不保存明文。资料继续存放在 `/data/sessions/<owner>/projects`。其中 owner 是稳定的工作空间编号，不再代表当前浏览器。模型与 PingCode 密钥仍由服务器加密保存。

浏览器登录有效期为 30 天；退出仅撤销当前登录，不撤销其他设备或已有 Codex MCP 连接。要撤销 MCP，请在「Codex 连接管理」中断开。上线前已授权的 MCP 凭据仍能访问原来的工作空间，注册绑定后继续指向同一账号空间。

没有默认账号或通用密码，每个人自行注册。当前不包含邮箱找回密码、团队共享、角色管理或实名审核。PingCode 提交使用该账号配置的应用凭据，其在 PingCode 中的身份仍由 PingCode 授权决定。

## 部署与验证

正常启动强制登录。`create_app(testing=True)` 默认保留匿名模式以兼容原有单元测试；认证用例显式设置 `auth_enabled=True`，覆盖旧数据认领、跨浏览器登录、账号隔离、凭据不回显、注销失效、重启持久化、CSRF 校验。部署须保留完整 `/data` 持久卷，包括 accounts.sqlite3、sessions 与 master.key。
