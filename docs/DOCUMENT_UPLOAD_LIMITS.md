# 文档上传容量

从 0.8.2 起，网页文件选择、拖拽、粘贴、MCP 导入和 CLI 文档生成采用统一的 50 MB（50,000,000 字节）上限。存储层使用同一上限；HTTP 导入请求为 JSON 转义和元数据预留空间。普通非导入请求仍沿用原有容量限制。

支持 Markdown、JSON、YAML 文档。该容量不代表支持 PDF、Word 或任意格式，也不等于模型上下文窗口；模型生成仍按接口分批。自动解析有独立的结构和引用检查，不能解析的文档可在网页保留原文交给 Codex 分析。

UI 测试的“测试要求附件”另支持 PNG/JPG/GIF/WebP、PDF、Word（doc/docx）、Excel（xls/xlsx）、PPT（ppt/pptx）、TXT/Markdown/CSV/TSV/JSON/YAML/RTF。每个会话最多 10 个附件，总大小为 50 MB；可只上传附件而不填写文字要求。原文件保存在所属会话的私有目录，图片可预览，其他文件按原格式下载；保存后可补充、移除。`get_test_document` 返回清单，`get_test_attachment` 按字节分块返回原内容；免安装客户端的 `download-attachment` 自动还原并核对 SHA-256。这里不使用 API 文档解析器，不调用外部模型，也不把附件内容视为系统指令或新的执行授权。

部署为大文档解析预留 2 GB 容器内存和 256 MB 临时目录。增加的是容器资源上限，不会预先分配这些内存。

验证包含 50 MB 文档导入及原文哈希回读、超限中文拒绝且不创建会话、JSON 转义后的 MCP 导入、前端选文件和粘贴的容量校验。
