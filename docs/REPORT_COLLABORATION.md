# 登录账号共同修改测试报告

报告链接不再按创建账号限制编辑。任意已登录平台账号可打开同一链接，读取和修改同一份报告的可编辑数据。未登录访问与专用公网只读端口继续只读。已有报告即时适用，不复制报告或迁移账号数据；原存储账号仅作为历史文件的定位信息。

状态保留各自的事实来源：

- 用例结果、说明和报告总结：修改以更正记录保存，原始报告、执行快照和截图保留。读取和导出应用同一份更正。
- 总报告：继续按用例编号汇总最新阶段结果；从总报告修正用例时写回其来源阶段，核对来源阶段及更正版本，避免把旧表单写进新的执行阶段。
- 缺陷处理：待提交、已提交、拒绝、暂缓、待回归、回归通过／失败仍是独立的处理状态。人工更正用例为通过不会自动声称已回归，也不会取消已提交的外部缺陷。状态修改核对更新版本，保留操作账号及理由。
- 规则、待确认操作与补测：使用原报告关联会话的持久状态，拒绝已过期的确认；已有待继续任务不能被另一条确认覆盖。补测仍保留原报告并发布独立阶段报告。
- 协作记录：成功修改记录操作账号、时间与操作类型，不记录请求正文、连接码或凭据。阶段／总报告共享变更提示，发现新修改只提示刷新，不自动丢弃当前输入。

账号的模型、PingCode 授权、机器人连接和未发布私人会话仍隔离。明确推送或重开外部缺陷、发送报告时使用操作人的集成配置；报告内的缺陷关联记录由所有协作者共用。

报告中的继续／补测连接只授权当前报告及其原始测试会话。该连接可读取所需资料、执行和发布该会话结果，不可枚举其他私人会话或创建无关任务。原有账号级 Codex 连接保留。

本改动包含既有断言更新和针对协作、旧版本冲突、总报告来源及限定连接的检查用例；发布仍走 MR 与 Jenkins 标准构建、启动和健康检查，不额外启动回归。
