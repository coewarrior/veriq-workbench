# 内网交付 · 0.7.0 · 2026-09-10

## 后续改动必须保持的产品约定

1. **内网用户打开网页即可使用。** 正常网页操作不依赖项目源码、Python、SSH 或 CLI；模型配置可选。首页提供不需要模型 Key 的完整体验。
2. **把网页的完整任务消息发给 Codex，就能知道怎么接入、读取资料并推进到报告。** 消息必须有真实 origin、当前会话和文档、用户目标、有效连接码、免安装接入说明。不能假设别人的 Codex 已安装某个 MCP，也不能把“连接成功”当任务完成。
3. 当前任务优先用已加载且指向正确地址的 MCP；未安装时，免安装客户端直接调用相同工具，MCP 注册不是任务完成的关卡。Codex 所在机器仍需能访问内网并允许终端执行，Python 客户端需要 3.9+。
4. 用户只要求检查文档时，直接分析并输出报告，不强制生成用例、补状态码、选环境或发送请求。完整测试则由 Codex 自行核对、执行与汇总，不退回网页要求用户逐步推进。
5. 部分检查缺条件时，完成其余检查并明确记录缺口。不能编造断言、请求、通过数或环境授权。
6. 会话和配置按账号隔离并由服务端持久化。每次运行保留冻结证据；完整报告 URL 可在内网免登录只读查看，工作空间与操作接口仍需登录。
7. 保留 Signal Particles 注册源码与原参数，界面沿用统一暗色主题；源码校验与重建方式见 `frontend/background/README.md`。

打开 http://192.0.2.20:18089/ 。首次可点击「体验完整流程」，不配置 Key 就能看到真实测试报告。

也可以在网页选择文档规则或自己的模型生成用例，再核对并执行。自己的内网测试目标由管理员登记允许地址；不是任意内网地址都开放执行。
