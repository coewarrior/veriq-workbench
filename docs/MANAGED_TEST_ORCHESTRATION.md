# 模式 A 实现进度与部署边界

2026-10-15，依据用户确认的设计 v1.10、D01–D15、C01–C03 和 P01/P02。控制面首阶段已于 0.15.0 发布；本次接入实际执行连接、受控浏览器、共享探索交接及用例报告链路。完整安装、执行图和适配边界见 [执行连接程序](MANAGED_RUNNER.md)。

## 责任与入口

| 组件 | 已实现职责 |
| --- | --- |
| 当前 Codex 聊天 / MCP | 根据用户指定项目与模块提交结构化计划；查询任务、提出停止/继续、按安全检查点拆分未派发模块；历史回归指定来源任务。不占用本聊天浏览器代跑托管任务。 |
| 平台控制器 | 同一事务保存任务、租约、派发和审计；检查结构、依赖、身份、完整账号集合、容量、公平顺位、恢复预算和版本；统一网页/MCP 两个入口。 |
| 执行连接 | 一次性配对与独立凭据；持久化派发映射；管理自己的隔离 Codex App Server；读取/续接原线程；消费中断与恢复事件；核实进程、浏览器和在途操作后交还资源。 |
| 受控浏览器 | 登录与身份核对；独立上下文；导航和逐请求规则；请求账本；真实观察、截图、明确标签切换与字节上传。测试账号与 host token 不进入模型隔离进程。 |
| 模块 Codex | 按当前授权探索、形成具体用例、执行时继续补充，保存证据与检查点，提出阶段完成或人工等待；不能自行批准共享规则、释放账号或标记执行机可信。 |
| 报告服务 | 每叶子模块独立 UI 记录；版本历史保留失败；按真实用例汇总覆盖、结果与剩余缺口；历史回归冻结旧用例并另建未执行记录。 |

## 本次串接的关键路径

- `/orchestration` 增加执行机配对/撤销/原机重新配对、登录身份配置、共享规则版本、人工现场核实与真实用例总览。
- 新增 `api-test-runner`，使用独立 host 协议；普通 MCP 无注册主机、取登录秘密或批准共享规则的能力。
- 账号与实际持有登录态的执行机一起匹配，容量随执行机资源更新；空闲执行账号优先，溢出可共享已核验探索账号。探索池耗尽后按资源和规则补充，不偷占正在执行账号。
- 阶段交接可在同一租约中原子转独占，保留浏览器；公平优先者存在时交还，并保留上下文亲和信息。多角色预留依赖真实交还信号，有期限、次数和不续期约束。
- Codex 模型进程退出不直接等于释放账号。未知请求、未核实现场保持隔离；人工确认仍需原执行机核对撤权。
- 发布排空时停止新分配，保留执行端报告、停止及交还通道；有效租约仍计入排空，不为上线强制清除现场。

## 既有行为保护

不改旧直接测试入口，不降低 BC-10/BC-11 的完整覆盖、先探索、持续补充与独立判定。使用现有 `ui_records` 保存与发布；不把一批浏览器操作当作一条合并结论，不把模块完成率当作用例通过率。不发起 PingCode 写入，不以历史通过代替本轮观察。

## 运行条件和未验收项

代码链路具备可安装入口，但真实运行仍要求：Mac 原生执行连接或同机 Linux Docker 执行机、本人 Codex 登录、目标系统账号和真实身份核验、经维护者核验的共享请求规则。Mac 无需 Docker，已有本机隔离/Codex 协议/浏览器启动自检；业务账号尚未提供，不宣称真实业务端到端验收。详见 `docs/MANAGED_RUNNER.md`。

通用 WebSocket 业务回执、非 GET 自动重放、XHR 重定向以及逐字流式展示时序不在当前通用浏览器适配能力内，必须如实记为受限检查；详见执行连接文档。机器与本地状态永久丢失必须按事故核实，不能自动接管或清除未知租约。P03–P08 中未明确的外部通知、成本和保留运营策略仍不擅自启用。

## 存储与回退

沿用私有 `orchestration.sqlite3`，`BEGIN IMMEDIATE` 与 `synchronous=FULL`。新增字段兼容首阶段结构；账号凭据加密，host token 仅存哈希。执行机本地凭据、Codex 历史与浏览器存储不得进 Git。当前是单服务事务快照实现，不声称完成高吞吐多副本调度器。

发布仍通过专用 GitLab MR 和 Jenkins。回退须先排空/核实执行租约；保留数据库和执行机状态，不靠删除数据回避未知业务结果。首阶段曾通过隔离单元与协议检查；本次依据当前交付偏好仅做编译、语法、差异及标准发布检查，不将其说成业务回归验收。
