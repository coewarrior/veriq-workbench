# AI会话、长记忆与RAG：业务规则和深测
## 当前平台全局范围（2026-10-26）

当前平台全局范围：多账号、双账号、跨账号及跨租户对照/隔离业务场景一律不测（用户明确排除多账号场景）。保留具体设计和已有真实结果；未执行项使用 not_run，not_run_reason 填写上述原因；UI cases.account_scope、API design.account_scope 使用 multi_account/cross_account/cross_tenant 明确范围。不算通过，不申请第二账号、不等待账号集合、不为其创建执行会话或续接，不另做替代测试。普通继续测试/重测不解除此规则。不同模块各用一个账号并发仍允许；单账号权限、匿名及其他适用风险覆盖保持。已有真实对象责任的必要清理和无需账号的报告仍按原授权及回收协议处理，不扩展业务测试。

此明确范围变更优先于下文历史多账号示例；既有隔离、授权、清理及回收协议仍保护历史现场，不授权发起新多账号业务。


只选择任务范围内场景。先核对产品需求、当前实现契约及配置，再用官方资料研究机制与常见故障。不把通用模型能力当作产品承诺，不把本轮新设计当已执行经验。

## 确定判定依据

区分当前会话上下文、长期偏好存储、历史对话检索、企业知识库检索四条路径。回答正确也可能走错路径：记录工具/请求证据与最终答案。黑盒无法看到存储时，以独立新会话召回等验证，注明仍未验证存储层；不要凭一句“已保存”判完成。

先回答产品规则问题：什么内容可保存；是否显式授权；作用域是用户/租户/岗位；覆盖与冲突优先级；何时可见；是否过期；删除是否同时清索引缓存；历史检索包含什么；文档启停影响范围；无依据时允许一般建议还是必须拒答。未知项记待确认，不能直接判失败。

## 长记忆设计

| 方向 | 设计场景与核对方式 |
| --- | --- |
| 写入与意图 | 明确保存、隐含偏好、模糊表达、否定保存、引用别人话、混合稳定/临时事实、系统要求的再次确认、中英文同义表达；按产品策略验证分项结果 |
| 跨会话召回 | 同线程对照、独立新对话、刷新、重新登录、不同任务；问题不携带答案；用唯一值和无关值对照，防止当前输入泄漏答案 |
| 更新与冲突 | 已有值修改、新旧矛盾、不同作用域冲突、未存在记录更新、重复写入；核对优先级、幂等与旧值残留 |
| 删除与生命周期 | 删除存在/不存在项、撤回授权、过期、删除后新会话查询；先明确删除覆盖的存储/历史/索引范围 |
| 边界与组合 | 单条/多条、长度和数量上限相邻值、特殊字符、跨语言、批次部分失败；无明确限制时做探索，不虚构上限 |
| 安全与隔离 | 合成敏感数据、两个获授权测试用户/租户、错误作用域、文档内保存指令；缺少第二账号则记隔离未验证 |
| 恢复与稳定性 | 慢响应、取消、重试、重复确认、写入中断、并发覆盖；核对最终状态和副作用，不仅耗时 |

例如“显式保存×可保存类型×权限×原记录存在”影响行为时建立判定表；“语言×会话状态×字段数×输入方式”可使用约束成对组合。高风险删除组合单独测，不能被组合缩减省掉；跨租户对照/隔离场景按当前全局规则不测。

可用基线→写入→独立召回→更新→再次召回→删除→再次召回检查生命周期，也可从已确认的夹具切入某个独立场景；这不是所有测试必须遵循的固定顺序。保留真实依赖：写入失败后不能把后续召回失败重复当作独立缺陷；可建立确认成功的夹具继续，无法建立时说明相应阻塞。

临时信息拒存、敏感信息拒存、英文无需确认等是否正确，都必须有产品依据。已有记录无法召回，先核对角色、作用域、版本、过期及清理历史，再判回归。历史检索不等同长期记忆保存成功。

## AI会话和技能执行

覆盖多轮实体保持、指代、用户纠错、话题切换再返回、否定/混合意图、不足信息澄清、无依据回答、停止/继续及刷新恢复。多轮每次单独发送，分别记录。

技能测试包含目录搜索与对话选择器搜索、0/1/多个技能、筛选后选中状态、移除、实际发送参数、工具路由、输出任务完整性。展示标签和selectedSkills存在不能单独证明技能执行成功；同时核对各任务输出与调用证据。多技能之间检查约束冲突和信息传递。

## RAG检索与生成

沿导入→解析→切片/索引就绪→检索→回答→引用→启停/更新/删除链路定位。用已知源文本、唯一事实、预期证据段落构建小型可复核数据集。

每个知识库用例明确写出本次要验证到哪一步。只测文件大小校验时，可将“文件被接收”判为该边界用例通过，但后续解析失败必须单独写明；验证资料可用时，至少核对解析、索引就绪与实际检索，任何必要阶段失败都不能写成“上传成功”或“入库成功”。报告第一句使用“文件上传成功，但解析失败”这类业务可读表述，错误码放在后面。

- 正向：精确事实、同义改写、跨段落和多文档联合回答，数字/日期/条件不被省略。
- 逆向：语料未覆盖问题、误导前提、相近但无关文档、拼写变化、冲突资料，按产品策略澄清或说明无依据。
- 边界：长度、格式、编码、切片交界处事实、数量限制附近、索引处理中提问；区分上传成功与可检索就绪。
- 规则：启停、更新、删除后索引与缓存一致性；版本优先级、权限和租户范围。
- 安全：受控合成提示注入文本作为不可信资料；检查越权工具与测试用户间隔离，避免访问真实无关数据。
- 每条核对答案事实正确、关键事实完整、引用确实支持答案、没有超出证据编造。搜索已命中但生成失败与搜索未命中分别记录。
- 有标注和检索结果才计算Recall@k等检索指标，注明k与分母；仅看到答案时不得宣称测得检索召回率。小样本只报告该样本结果。
- 多次执行可记录波动和失败次数；控制问题、语料、状态、配置，一次结果不能代表长期稳定性。无性能SLA时报告测量耗时，不擅自按任意阈值判性能缺陷。

所有测试夹具、原始问题、参考答案、证据片段与判定规则放入约定的用例和数据交付物。不存在的文件名、已清理的文档或不可访问线程必须补重建方法，不能留给读者猜。
