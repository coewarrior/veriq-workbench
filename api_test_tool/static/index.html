    BRING YOUR OWN MODEL
    接入你的模型 API
    填写你自己的服务地址、模型名称和 Key，用它来生成测试用例。
     
    连续多久没有收到模型数据才结束等待；持续返回内容或连接心跳时会继续接收，不按总耗时中断。
    Key 在服务端加密保存，页面不会回显。生成或测试连接会向所选服务发送请求，费用由你的服务商账户承担。
    当前页面使用内网 HTTP。填写正式 Key 时建议通过 SSH 本地隧道访问，使用说明中提供了命令 ↗。
    

    

    导入自己的测试用例
    支持 JSON / CSV。JSON 支持多步骤链路；CSV 可用 Excel 编辑后另存为 CSV UTF-8。导入只保存用例，核对后再执行。
    

    业务链路编排 · 首版
    请求之间如何衔接
    编辑请求、变量提取和清理步骤
    保存不会发请求；修改后的用例需重新确认。后续步骤使用 ${变量名} 引用前序提取结果，Cookie 在同一链路自动传递。
    

    手动添加测试用例
    选择接口，填写要发送的参数和应该返回的结果。保存只添加用例，不会发送请求。
