连接 PingCode

在报告里审核缺陷，一键提交到团队项目。提交过程不调用大模型。

连接配置

正在读取…

在 PingCode 企业后台的凭据管理中创建应用，配置项目数据范围。凭据保存在服务器，页面不会回显。私有部署地址需由管理员允许访问。

如何获取 Client ID 和 Client Secret展开图解 ＋收起图解 −

按图中 1–4 的顺序进入 PingCode 凭据管理，复制你自己的应用凭据。

  1. 点击左上角的企业名称，打开企业菜单。
  2. 选择「管理后台」。
  3. 切换到「应用」，进入左侧「凭据管理」。
  4. 展开对应应用，分别点击 Client ID 和 Secret 旁的复制按钮，粘贴到上方同名输入框。

没有对应应用时，可由管理员在「凭据管理」中新建应用并配置项目数据范围。填好上方连接配置后，点击「保存并读取项目」，再选择默认项目与缺陷类型。

默认提交项目

选好默认值后，每条缺陷仍可在审核窗口修改。

怎样提交缺陷

  1. 打开测试报告，在问题旁点击「提交到 PingCode」。
  2. 核对标题、描述、项目、负责人和项目字段。
  3. 勾选已审核，点击「确认并推送」。成功后显示缺陷编号。

文档检查发现也可提交。执行异常需要先判断是否为产品缺陷。提交者身份取决于 PingCode 授权；测试台数据按登录账号隔离，账号与 PingCode 成员身份不自动对应。
