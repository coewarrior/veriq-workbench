# 内置示例的停测依据

来源：原独立项目 README.md（5154858），仅保留平台示例规则引用的停测说明。

## 当前停测用例说明

为避免已知缺陷持续打崩服务，当前以下用例已临时停测：

| 用例编号 | 场景说明 | 停测原因 |
|---|---|---|
| `TC-INF-005` | `SSID=99999999` | 已确认会触发服务端 `stoi` 异常并导致进程崩溃 |
| `TC-INF-008` | `SSID=abc` | 已确认属于危险 `SSID` 场景，可能直接打崩服务 |
| `TC-INF-009` | `SSID=-1` | 已确认属于危险 `SSID` 场景，可能直接打崩服务 |
| `TC-INF-010` | `SSID=9999999999999999` | 已确认会触发服务端异常并导致服务退出 |
| `TC-INF-011` | 篡改 `SSID` 尝试越权访问 | 已捕获服务端建会话后再次因 `stoi` 异常崩溃 |

说明：

- 上述用例不是删除，而是临时跳过。
- 待服务端修复对应缺陷后，应恢复这些用例继续执行。
- 具体缺陷信息请查看 [缺陷报告.md](缺陷报告.md)。
