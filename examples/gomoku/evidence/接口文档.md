# 接口文档

## 基本信息

| 项目 | 说明 |
|------|------|
| 服务名称 | 五子棋 Web 服务 |
| Base URL | `http://198.51.100.10:8081` |
| 数据格式 | JSON |
| 编码 | UTF-8 |

---

## 1. 用户注册

| 项目 | 说明 |
|------|------|
| 编号 | 1 |
| 名称 | 用户注册 |
| URL | `/reg` |
| 完整地址 | `http://198.51.100.10:8081/reg` |
| 请求方法 | POST |
| 请求参数 | **请求头：** `Content-Type: application/json`<br><br>**Body（JSON）：**<br>• `username` string，必填，用户名，示例：`admin`<br>• `password` string，必填，密码，示例：`123456`<br><br>**请求示例：**<br>`{"username":"admin","password":"123456"}` |
| 正确响应结构 | **字段说明：**<br>• `reason` string，成功提示信息<br>• `result` boolean，成功时为 `true`<br><br>**响应示例：**<br>`{"reason":"用户注册成功！","result":true}` |
| 错误响应结构 | **仅三种错误应答：**<br><br>**1. 重复注册：**<br>`{"reason":"用户名已被占用！","result":false}`<br>说明：空格字符 `" "` 可以注册，但重复注册同一用户名时返回该错误。<br><br>**2. 账号/密码为空：**<br>`{"reason":"请输入账号/密码","result":false}`<br><br>**3. Content-Type 错误：**<br>`{"reason":"正文格式有问题!","result":false}` |

---

## 2. 用户登录

| 项目 | 说明 |
|------|------|
| 编号 | 2 |
| 名称 | 用户登录 |
| URL | `/login` |
| 完整地址 | `http://198.51.100.10:8081/login` |
| 请求方法 | POST |
| 请求参数 | **请求头：** `Content-Type: application/json`<br><br>**Body（JSON）：**<br>• `username` string，必填，用户名，示例：`admin`<br>• `password` string，必填，密码，示例：`123456`<br><br>**请求示例：**<br>`{"username":"admin","password":"123456"}`<br><br>**备注：** 登录成功后服务端通过 Cookie 下发 `SSID` 作为鉴权信息。 |
| 正确响应结构 | **字段说明：**<br>• `reason` string，成功提示信息<br>• `result` boolean，成功时为 `true`<br><br>**响应示例：**<br>`{"reason":"用户登录成功！","result":true}` |
| 错误响应结构 | **仅两种错误应答：**<br><br>**1. 账号/密码错误：**<br>`{"reason":"账号/密码错误!","result":false}`<br><br>**2. 账号/密码为空：**<br>`{"reason":"请输入账号/密码","result":false}` |

---

## 3. 信息获取接口

| 项目 | 说明 |
|------|------|
| 编号 | 3 |
| 名称 | 获取用户信息 |
| URL | `/info` |
| 完整地址 | `http://198.51.100.10:8081/info` |
| 请求方法 | GET |
| 请求参数 | **请求头：**<br>`Cookie: SSID=6`<br><br>**参数说明：**<br>• `SSID` string，登录成功后的鉴权信息 |
| 正确响应结构 | **字段说明：**<br>• `id` int，用户 ID<br>• `score` int，积分<br>• `total_count` int，总对局数<br>• `username` string，用户名<br>• `win_count` int，胜局数<br><br>**响应示例：**<br>`{"id":2,"score":1000,"total_count":0,"username":"xiaoming","win_count":0}` |
| 错误响应结构 | **仅三种错误应答：**<br><br>**1. 登录过期：**<br>`{"reason":"登录过期，请重新登录！","result":false}`<br><br>**2. Cookie 信息异常：**<br>`{"reason":"cookie信息，请重新登录！","result":false}`<br><br>**3. 找不到 SSID：**<br>`{"reason":"找不到SSID，请重新登录！","result":false}` |

---

## 通用说明

| 项目 | 说明 |
|------|------|
| 鉴权字段 | `SSID`，通过 Cookie 传递 |
| 成功标识 | 注册、登录接口返回 `result=true`；信息接口返回用户数据对象 |
| 失败标识 | 接口失败时返回 `reason` 和 `result=false` |
| 特殊说明 | 空用户名、空密码不可以注册，但字符 `" "` 可以注册 |
| 补充说明 | 用户名对大小写不敏感，该场景不纳入测试范围 |
