# 测试用例

## 基本信息

| 项目 | 说明 |
|------|------|
| 文档名称 | 五子棋 Web 服务接口测试用例 |
| 依据文档 | [接口文档.md](./接口文档.md) |
| Base URL | `http://198.51.100.10:8081` |
| 数据格式 | JSON |
| 编码 | UTF-8 |

## 项目背景

| 项目 | 说明 |
|------|------|
| 项目性质 | 后端开发练习项目 |
| 注册规则 | 用户名和密码字符长度均需大于 0 |
| 无需测试项 | SQL 注入、XSS、验证码、邮箱相关能力 |
| 特殊说明 | 空用户名、空密码不允许注册，但字符 `" "` 可以注册 |
| 额外约束 | 用户名大小写不敏感，该场景不纳入测试范围 |

## 1. 用户注册（POST `/reg`）

| 编号 | 名字 | 测试类型 | 输入参数 | 预期结果 |
|:----:|------|:--------:|----------|----------|
| TC-REG-001 | 正常注册新用户 | 正向 | **URL：** `http://198.51.100.10:8081/reg`<br>**方法：** POST<br>**请求头：** `Content-Type: application/json`<br>**Body：** `{"username":"testuser001","password":"123456"}` | 返回 `{"reason":"用户注册成功！","result":true}` |
| TC-REG-002 | 用户名和密码均为 1 字符 | 正向 | **Body：** `{"username":"a","password":"1"}` | 返回 `{"reason":"用户注册成功！","result":true}` |
| TC-REG-003 | 注册后用户可用于后续登录 | 正向 | ① POST `/reg`，Body：`{"username":"testuser002","password":"123456"}`<br>② 再调用登录接口使用相同账号密码 | 注册成功，且后续登录成功 |
| TC-REG-004 | 注册空格用户名 | 边界 | **Body：** `{"username":" ","password":"12"}` | 返回 `{"reason":"用户注册成功！","result":true}` |
| TC-REG-005 | 注册包含特殊字符的用户名 | 边界 | **Body：** `{"username":"user@#$","password":"123456"}` | 不返回 500，记录实际结果 |
| TC-REG-006 | 注册超长用户名 | 边界 | **Body：** username 为 256 字符，password=`123456` | 不返回 500，记录实际结果 |
| TC-REG-007 | 用户名已存在 | 逆向 | **Body：** `{"username":"admin","password":"123456"}` | 返回 `{"reason":"用户名已被占用！","result":false}` |
| TC-REG-008 | 用户名为空 | 逆向 | **Body：** `{"username":"","password":"123456"}` | 返回 `{"reason":"请输入账号/密码","result":false}` |
| TC-REG-009 | 密码为空 | 逆向 | **Body：** `{"username":"newuser001","password":""}` | 返回 `{"reason":"请输入账号/密码","result":false}` |
| TC-REG-010 | 用户名和密码均为空 | 逆向 | **Body：** `{"username":"","password":""}` | 返回 `{"reason":"请输入账号/密码","result":false}` |
| TC-REG-011 | 缺少 username 字段 | 逆向 | **Body：** `{"password":"123456"}` | 返回 `{"reason":"请输入账号/密码","result":false}` |
| TC-REG-012 | 缺少 password 字段 | 逆向 | **Body：** `{"username":"newuser002"}` | 返回 `{"reason":"请输入账号/密码","result":false}` |
| TC-REG-013 | 请求体为空 | 逆向 | **Body：** `{}` | 返回 `{"reason":"请输入账号/密码","result":false}` |
| TC-REG-014 | Content-Type 错误 | 逆向 | **请求头：** `Content-Type: text/plain`<br>**Body：** `username=admin&password=123456` | 返回 `{"reason":"正文格式有问题!","result":false}` |
| TC-REG-015 | 并发重复注册同一用户名 | 安全 | 同一用户名并发发送 2 个 POST `/reg` 请求 | 仅 1 次成功，另 1 次返回 `{"reason":"用户名已被占用！","result":false}` |

## 2. 用户登录（POST `/login`）

| 编号 | 名字 | 测试类型 | 输入参数 | 预期结果 |
|:----:|------|:--------:|----------|----------|
| TC-LOG-001 | 正确账号密码登录 | 正向 | **URL：** `http://198.51.100.10:8081/login`<br>**方法：** POST<br>**请求头：** `Content-Type: application/json`<br>**Body：** `{"username":"admin","password":"123456"}` | 返回 `{"reason":"用户登录成功！","result":true}`，响应中包含 `SSID` Cookie |
| TC-LOG-002 | 注册后新用户登录 | 正向 | 先注册 `{"username":"loginuser001","password":"123456"}`，再 POST `/login` 使用相同账号密码 | 登录成功，响应中包含 `SSID` Cookie |
| TC-LOG-003 | 1 字符账号密码登录 | 正向 | 先注册 `{"username":"x","password":"9"}`，再登录 `{"username":"x","password":"9"}` | 返回 `{"reason":"用户登录成功！","result":true}` |
| TC-LOG-004 | 登录成功后访问 `/info` | 正向 | ① POST `/login` 成功<br>② 携带 `SSID` 访问 `/info` | `/info` 返回当前登录用户信息 |
| TC-LOG-005 | 密码错误 | 逆向 | **Body：** `{"username":"admin","password":"wrongpwd"}` | 返回 `{"reason":"账号/密码错误!","result":false}` |
| TC-LOG-006 | 用户名不存在 | 逆向 | **Body：** `{"username":"notexist999","password":"123456"}` | 返回 `{"reason":"账号/密码错误!","result":false}` |
| TC-LOG-007 | 用户名为空 | 逆向 | **Body：** `{"username":"","password":"123456"}` | 返回 `{"reason":"请输入账号/密码","result":false}` |
| TC-LOG-008 | 密码为空 | 逆向 | **Body：** `{"username":"admin","password":""}` | 返回 `{"reason":"请输入账号/密码","result":false}` |
| TC-LOG-009 | 用户名和密码均为空 | 逆向 | **Body：** `{"username":"","password":""}` | 返回 `{"reason":"请输入账号/密码","result":false}` |
| TC-LOG-010 | 缺少 username 字段 | 逆向 | **Body：** `{"password":"123456"}` | 返回 `{"reason":"请输入账号/密码","result":false}` |
| TC-LOG-011 | 缺少 password 字段 | 逆向 | **Body：** `{"username":"admin"}` | 返回 `{"reason":"请输入账号/密码","result":false}` |
| TC-LOG-012 | 用户名前后带空格 | 边界 | **Body：** `{"username":" admin ","password":"123456"}` | 返回 `{"reason":"账号/密码错误!","result":false}` |
| TC-LOG-013 | 连续错误登录无锁定 | 安全 | 同一账号连续 10 次使用错误密码登录 | 每次均返回 `{"reason":"账号/密码错误!","result":false}` |
| TC-LOG-014 | 未注册账号登录 | 安全 | **Body：** `{"username":"hacker001","password":"123456"}` | 返回 `{"reason":"账号/密码错误!","result":false}` |

## 3. 获取用户信息（GET `/info`）

| 编号 | 名字 | 测试类型 | 输入参数 | 预期结果 |
|:----:|------|:--------:|----------|----------|
| TC-INF-001 | 登录后正常获取信息 | 正向 | **URL：** `http://198.51.100.10:8081/info`<br>**方法：** GET<br>**请求头：** `Cookie: SSID=<登录后返回值>` | 返回包含 `id`、`score`、`total_count`、`username`、`win_count` 的用户信息 |
| TC-INF-002 | 返回数据与登录用户一致 | 正向 | 用户 `infouser001` 登录后访问 `/info` | 返回数据中的 `username` 与登录用户一致 |
| TC-INF-003 | 未携带 Cookie | 逆向 | GET `/info`，不传 Cookie | 返回信息接口错误应答之一，`result=false` |
| TC-INF-004 | Cookie 中缺少 SSID | 逆向 | **请求头：** `Cookie: token=123` | 返回 `{"reason":"找不到SSID，请重新登录！","result":false}` |
| TC-INF-005 | SSID 无效 | 逆向 | **请求头：** `Cookie: SSID=99999999` | 返回信息接口错误应答之一，`result=false` |
| TC-INF-006 | SSID 为空 | 逆向 | **请求头：** `Cookie: SSID=` | 返回信息接口错误应答之一，`result=false` |
| TC-INF-007 | Cookie 格式错误 | 逆向 | **请求头：** `Cookie: invalid_format` | 返回信息接口错误应答之一，`result=false` |
| TC-INF-008 | SSID 为非数字 | 边界 | **请求头：** `Cookie: SSID=abc` | 返回信息接口错误应答之一，`result=false` |
| TC-INF-009 | SSID 为负数 | 边界 | **请求头：** `Cookie: SSID=-1` | 返回信息接口错误应答之一，`result=false` |
| TC-INF-010 | SSID 为超大值 | 边界 | **请求头：** `Cookie: SSID=9999999999999999` | 返回信息接口错误应答之一，`result=false` |
| TC-INF-011 | 篡改 SSID 尝试越权访问 | 安全 | 用户 A 登录后，手工修改 Cookie 中的 `SSID` 值再访问 `/info` | 不返回其他用户敏感信息，返回错误应答或当前合法会话数据 |
| TC-INF-012 | 未登录直接访问 | 安全 | 不经过 `/login` 直接访问 `/info` | 返回信息接口错误应答之一，`result=false` |

## 4. 接口调用流程

| 编号 | 名字 | 测试类型 | 输入参数 | 预期结果 |
|:----:|------|:--------:|----------|----------|
| TC-FLOW-001 | 完整业务流程 | 正向 | ① POST `/reg` 注册新用户<br>② POST `/login` 登录<br>③ GET `/info` 获取用户信息 | 三步均成功，`/info` 返回该用户信息 |
| TC-FLOW-002 | 未注册直接登录后访问信息接口 | 逆向 | ① 不注册直接 POST `/login`<br>② 再访问 `/info` | 登录失败，`/info` 返回错误应答 |
| TC-FLOW-003 | 注册成功但未登录直接访问信息接口 | 逆向 | ① POST `/reg` 注册成功<br>② 不登录直接访问 `/info` | 注册成功，`/info` 返回错误应答 |

## 通用说明
